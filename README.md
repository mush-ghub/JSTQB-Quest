# QAクエスト ～JSTQB Foundation Level RPG学習教材～

JSTQB Foundation Level（シラバス v4.0）を、RPG風の冒険ストーリーで学べる学習教材です。

## 内容
- 本編：全6章の冒険ストーリー（各章に「試験で問われるポイント」「現場で役立つポイント」「よくある引っ掛け問題」のまとめ付き）
- 全6章：アニメーション付きの図解（第1章12点・第2〜6章37点）と、各章のミニチェック（タップで答えが出るカード）
- 最終試練：模擬試験 20問
- 高難易度模試：40問×5回（本番形式・60分タイマー・「2つ選べ」問題あり）
- 全220問に、選択肢ごとの「なぜ正解か／なぜ不正解か」の解説付き

## 学習ツール
- 用語辞典（105語）：本文中の点線付きの用語をタップすると意味をポップアップ表示。関連する図解をアニメーション付きで開ける。検索・章別の絞り込みあり
- 練習モード：全220問から問題数（10・20・40問）と章を選んでランダム出題
- 復習モード：間違えた問題と、模試で「見直し」を付けた問題だけを解き直し。正解するとリストから外れる
- 成績の記録：模試ごとの最高点・前回の点数、章別の正答率、最近の履歴を表示

記録はブラウザのローカルストレージにのみ保存され、外部には送信されません（端末・ブラウザごとに別々の記録になります）。

## 使い方
`index.html` をブラウザで開くだけで使えます（インターネット接続は不要）。
GitHub Pages で公開している場合は、公開URLにアクセスしてください。

## 図解について
図解・イラストはすべて本教材のために新規作成したSVGで、外部素材は使用していません。
OSの「視差効果を減らす（動きを減らす）」設定がオンの場合、アニメーションは再生されず完成図が表示されます。

## 注意
本教材は学習用に作成した独自の問題集であり、JSTQB／ISTQBの公式教材ではありません。
試験の最新情報は [JSTQB公式サイト](https://jstqb.jp) で確認してください。
